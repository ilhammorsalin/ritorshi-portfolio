# ritorshi-portfolio

Personal portfolio site. Auto-generated by `npm run docs:update` — edit `scripts/update-docs.mjs` to change content.

## Stack

- Next.js 16.4.2, React 19.3.0, TypeScript
- Tailwind CSS ^4, shadcn/ui
- framer-motion ^14.6.0, next-themes ^0.4.6

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — `next dev`
- `npm run build` — `next build`
- `npm run start` — `next start`
- `npm run lint` — `eslint`
- `npm run format` — `prettier --write "**/*.{ts,tsx}"`
- `npm run typecheck` — `tsc --noEmit`
- `npm run docs:update` — `node scripts/update-docs.mjs`

- Path alias `@/*` → `./src/*`
- UI components in `src/components/ui`
- Typography via `Text` component variants
- Dark mode toggled with the `d` key
- Assets must live in `public/` to be served
